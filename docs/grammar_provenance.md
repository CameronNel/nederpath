# Grammar and comprehension provenance

This document records the reference basis for NederPath's core curriculum.
It does **not** copy copyrighted ANS, Taalunie, or Onze Taal wording.

## Method

Each lesson states a named phenomenon, gives phenomenon-specific rules, Dutch
examples with English glosses, a typical learner error, and exercises that
target that phenomenon. Exceptions are marked as exceptions, not hidden.
Passages are independently authored. They are not scraped and not
title-swapped templates.

## High-risk topics — exact claims and sources

| Topic | Claim taught | Source (organisation / work / topic) |
| --- | --- | --- |
| Open/closed syllables; v/z → f/s | Vowel length is shown by syllable type; stem-final *v/z* become *f/s* at syllable end. | Taalunie spelling rules; ANS morphology of stem alternation |
| Pronouns *hen* / *hun* / *ze* | Traditional written *hen* after prepositions and as DO; *hun* as IO; spoken *ze* is the default plural object. | Onze Taal *hen/hun/ze*; Taaladvies.net *hen of hun* |
| *de* / *het* | All plurals *de*; all diminutives *het*; compounds take the gender of the last noun; suffix heuristics leak. | ANS *Lidwoorden*; Taalunie *de of het* |
| Adjective *-e* | *een groot huis* vs *het grote huis*; *-e* after *de*/demonstratives/possessives and all plurals. | ANS *Bijvoeglijke naamwoorden — verbuiging* |
| Separable verbs | Prefix to clause-final in main clauses; *ge-* between prefix and stem in the participle. | ANS *Scheidbare werkwoorden* |
| *jij* inversion | Finite *-t* drops when *je/jij* follows the verb; *u* keeps the ending. | ANS *Congruentie*; Onze Taal *werk je / werkt u* |
| V2 vs SOV | Finite verb second in main clauses; all verbs clause-final after subordinators. | ANS *Woordvolgorde in de zin* |
| *er* | Existential, quantitative/partitive, and prepositional *er* (*ervan*) are distinct slots. | ANS *er*; Taalportaal *pronominal adverb* |
| Relatives | *die* after *de*-words and all plurals; *dat* after singular *het*-words; *waar*+P vs *met wie*. | ANS *Betrekkelijke bijzinnen* |
| *te* / *om te* | *om te* for purpose; bare *te* after many adjectives and some verbs (*blij zijn te*, *proberen te*). | ANS *Infinitiefconstructies* |
| *hebben* / *zijn* | *zijn* for telic motion/change plus *blijven/zijn/worden/gebeuren*; almost all transitives *hebben*. | ANS *Hulpwerkwoorden van tijd* |
| *'t kofschip* | Dental suffix decided on stem voicing **before** final-obstruent spelling: *leefde*, *reisde*. | Taalunie *'t kofschip / soft ketchup*; ANS weak past |
| Passive | *worden* = event; *zijn* + participle = result or perfect of a *worden*-passive. | ANS *Lijdende vorm* |
| IPP | After a modal/perception/causative + infinitive, the middle verb appears as infinitive (*heeft laten maken*). | ANS *Infinitivus pro participio* |
| Verb clusters | Both red (1–2, finite first) and green (2–1) orders occur in subordinates. | ANS *Werkwoordclusters*; Taalportaal *verb clustering* |
| Comparatives | Standard written *groter dan*; *als* after a comparative is marked; equative *zo/even … als*. | Onze Taal *groter dan / groter als*; Taaladvies.net |
| Circumpositions vs *ervan uitgaan* vs *van daaruit* | *op … na*, *tot … toe*, *van NP uit* wrap an NP. *Van daaruit* is spatial. *Uitgaan van* + *er/daar* is *ervan/daarvan uitgaan* (*we gaan ervan uit*), not *ervanuit*. | Taalportaal *Circumpositional phrases*; Onze Taal *Wat is goed: ervan uitgaan*; Taaladvies.net *We gaan ervan uit* |
| Particles | *nou, toch, even, maar, hoor, wel* change illocution, not the truth-conditional core. | ANS *Partikels*; Onze Taal particle notes |
| Formal *u* | *u* is the polite subject/object; verb keeps *-t* (*hebt u / heeft u*). | ANS *Aanspreekvormen*; Onze Taal *u* |
