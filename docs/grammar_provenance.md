# Grammar and comprehension provenance

This document records the reference basis for NederPath's core curriculum.
It does **not** copy copyrighted textbook or ANS wording.

## Reference families consulted (public grammatical consensus)

- Algemene Nederlandse Spraakkunst (ANS / Taalunie) — clause order, inversion,
  `er`, relative clauses, verb clusters, IPP, auxiliaries, adjective inflection.
- Taalunie spelling and morphology notes — open/closed syllables, `v/z` → `f/s`,
  `'t kofschip` / *soft ketchup* for weak past/participles.
- Onze Taal / taaladvies.net consensus — `hen`/`hun`, `als`/`dan`,
  `groter als` vs `groter dan`, register of `u`, particles.
- Standard pedagogical grammars of Dutch as a second language (structure only):
  present/past/perfect, separable vs inseparable prefixes, `te` / `om te`.

## Method

Each lesson states a named phenomenon, gives phenomenon-specific rules, Dutch
examples with English glosses, a typical learner error, and exercises that
target that phenomenon. Exceptions are marked as exceptions, not hidden.

Passages are independently authored scenes and argumentative texts. They are not
scraped, not title-swapped templates, and not expansions of a single paragraph.

## High-risk topics explicitly checked against the consensus above

Pronouns (full vs reduced; object `hen`/`hun`/`ze`); `de`/`het` heuristics;
adjective `-e`; separable verbs; `jij` inversion `-t` drop; V2 vs SOV;
pronominal `er`; relatives `die`/`dat`/`wie`/`waar`+prep; `te` / `om te`;
modals; `hebben`/`zijn`; OVT vs VTT; `'t kofschip`; passive `worden`/`zijn`;
IPP; verb clusters (red/green); reported speech; conditionals; particles;
formal/informal register; B2/C1 syntax.

IDs `g-001`–`g-120` and `comp-001`–`comp-004` are stable. New passages occupy
`comp-005`–`comp-120`.
